{ char s[1000], *p[100]; int k=0,n=0;
gets(s);
p[0] = s;
for(;s[k]; k++) if (s[k]==' ') { s[k]='\0'; n++; p[n]=&s[k+1];}

  <p>是的，for(;s[k]; k++) if (s[k]==' ') { s[k]=<strong>'\0';</strong> n++; p[n]=&amp;s[k+1];}</p>
