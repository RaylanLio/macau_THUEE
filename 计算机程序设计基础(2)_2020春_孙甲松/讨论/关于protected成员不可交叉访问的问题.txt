Topic关于protected成员不可交叉访问的问题

秦圣岭




在编程中发现，派生类如果公有继承基类，那么派生类的成员函数将只可以访问当前对象的基类protected成员，而不可以访问其他对象的protected成员。这与private成员可以交叉访问有点矛盾（一个对象可以通过其成员函数访问另一个对象的private成员），是什么原因呢？

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">是的，派生类如果公有继承基类，那么派生类的成员函数将只可以访问当前对象的基类protected成员，而不可以访问其他对象的protected成员。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">class Point {</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; public: void Display( ) const</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; { cout &lt;&lt; X &lt;&lt; ',' &lt;&lt; Y &lt;&lt; endl; }</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; protected: int X, Y;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">};</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">class Line: public Point {</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; public: &nbsp;void Display( ) const; </span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; private: Point p2;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">};</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">void Line ::Display( ) const</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">{ Point::Display( );&nbsp; p2.Display( );&nbsp; }</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">基类成员改为protected，那么派生类Line的Display函数可以改为：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">void Line ::Display( ) const</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">{ cout &lt;&lt;this-&gt;X &lt;&lt; this-&gt;Y; &nbsp;&nbsp;&nbsp;p2.Display( );&nbsp; }</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">可以直接访问基类的保护成员。但不可以改为：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">void Line ::Display( ) const</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">{ cout &lt;&lt;this-&gt;X &lt;&lt; this-&gt;Y; &nbsp;&nbsp;&nbsp;cout &lt;&lt;p2.X &lt;&lt;p2.Y; &nbsp;}</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">会出现编译错误：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">test.cpp(36) : error C2248: “Point::X”: 无法访问 protected 成员(在“Point”类中声明)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">test.cpp(36) : error C2248: “Point::Y”: 无法访问 protected 成员(在“Point”类中声明)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">派生类不能直接访问内嵌对象p2的保护成员。因为在编译器看来内嵌对象与所继承的基类对象没什么内在联系。这与一个对象可以通过其成员函数访问另一个同类对象的private成员完全不是一回事。</span></p>
