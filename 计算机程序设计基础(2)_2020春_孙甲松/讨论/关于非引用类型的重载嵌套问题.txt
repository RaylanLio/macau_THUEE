老师请问以下为什么会在>=重载处显示“类String没有适当的复制构造函数”？
另外，为什么在把重载的形参改为引用类型后就没有错误了？
（以下省略无关的函数）
class String
{ public:     String(String &str);     bool operator ==(const String s1);     bool operator >(const String s1);     bool operator <(const String s1);     bool operator >=(const String s1); private:     char *s; };
String::String(String &str) {     s = new char[strlen(str.s)+1];     strcpy(s,str.s);     cout<<"copy constructer is called."<<endl; } bool String::operator ==(const String s1) {     return(!strcmp(s,s1.s)); } bool String::operator >(const String s1) {     return(!(strcmp(s,s1.s)-1)); } bool String::operator <(const String s1) {     return(!(strcmp(s,s1.s)+1)); } bool String::operator >=(const String s1) {     return(*this > s1||*this==s1); }

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">编译出现错误提示：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">test.cpp(35): error C2679: 二进制“&gt;”: 没有找到接受“const String”类型的右操作数的运算符(或没有可接受的转换)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;test.cpp(9): 可能是“bool String::operator &gt;(const String)”</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">指：&nbsp; return(*this &gt; s1||*this==s1); 这一行有错，是因为你重载的关系操作符函数为：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;bool String::operator &gt;(const String s1)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">形参是常对象，执行&gt;操作符函数时，需要调用复制构造函数传递形参，而且复制构造函数必须是常引用才行，所以你需要把复制构造函数头部：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;String(String &amp;str);</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">改为: String(const String &amp;str);</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">才不会出现上述编译错误。或者把</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;bool String::operator &gt;(const String s1)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">形参改引方式: bool String::operator &gt;(const String &amp;s1)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">这样传递参数时不需要调用复制构造函数，也不会出现上述编译错误。</span></p>
