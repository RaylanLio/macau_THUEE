Topic与常引用类型相关问题

一些资料上认为当常引用所引用类型为变量时会产生一个临时量，常引用就绑定在这个临时量上，比如
int dval = 1;
const int &ri = dval;
相当于
const int temp = dval;
const int &ri = temp;
但是这么说的话如果再改变dval的值，ri的值应该不变，因为ri绑定到temp而非dval上。
但是验证表明ri会改变，这是什么原因？

  <p>int dval = 1;</p> 
  <p>const int &amp;ri = dval;</p> 
  <p>dval 是普通变量，可以随时修改，而ri是常引用，不能修改。</p> 
  <p>dval =2; 没有问题，ri的值也变成2。</p> 
  <p>但是 ri=2; 会产生编译错误：error C3892: “ri”: 不能给常量赋值</p> 
  <p>&nbsp;</p> 
  <p>程序：</p> 
  <p>#include&lt;iostream&gt;<br> using namespace std;<br> void &nbsp;main()<br> { int dval = 1;<br> &nbsp; const int temp = dval;<br> &nbsp; const int &amp;ri = temp;<br> &nbsp; cout &lt;&lt;dval &lt;&lt; " " &nbsp;&lt;&lt;temp &lt;&lt; " " &lt;&lt; ri &lt;&lt; endl;<br> &nbsp; dval = 2;<br> &nbsp; cout &lt;&lt;dval &lt;&lt; " " &nbsp;&lt;&lt;temp &lt;&lt; " " &lt;&lt; ri &lt;&lt; endl;<br> }</p> 
  <p>运行结果：&nbsp;</p> 
  <p>1 1 1<br> 2 1 1<br> 请按任意键继续. . .&nbsp; &nbsp;</p> 
  <p>改变dval的值，temp和ri的值都没有改变。</p> 
  <p>&nbsp;</p> 
  <p>int dval = 1;<br> &nbsp; &nbsp; &nbsp; &nbsp;const int &amp;ri = 2*dval;</p> 
  <p>ri引用的是表达式，不是dval变量，所以无法绑定地址，只能另外在常量区为ri开辟内存存放2*dval的值。</p> 
  <p>因此以后dval改变与ri无关。</p>
