课本练习5第19题
我觉得“错误输入”应该不仅是非四位的整数，还应包括浮点数。
可以看到，当小数点后足够小的时候，用强制转化后相比较的方法无法判断输入是否为整型数。
我的问题：如何判断输入的数是不是整型数（精确的方法）？
 
源代码：（后附运行结果）
#include<stdio.h>
main()
{
    double y;
    int x,a,b,c,d,t;
    printf("input a four figures number\n");
    scanf("%lf",&y);
    x=(int)(y);
    if(x!=y) printf("error input!\n");
    else if(x>9999||x<1000) printf("error input!\n");
    else
    {
    a=x/1000;
    b=(x%1000)/100;
    c=(x%100)/10;
    d=x%10;
    printf("inverted number:%d%d%d%d\n",d,c,b,a);
    if(a<b) t=a,a=b,b=t;
    if(a<c) t=a,a=c,c=t;
    if(a<d) t=a,a=d,d=t;
    if(b<c) t=b,b=c,c=t;
    if(b<d) t=b,b=d,d=t;
    if(c<d) t=c,c=d,d=t;
    printf("maximum:%d%d%d%d\n",a,b,c,d);
    printf("minimum:%d%d%d%d\n",d,c,b,a);
    }
}
