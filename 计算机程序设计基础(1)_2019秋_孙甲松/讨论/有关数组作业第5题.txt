请问为什么这个程序编译没问题，能输出正确结果，但输出结果之后会显示致命错误Stack around the variable'c' is corrupted?

#include<stdio.h> int Findmin(int b[], int i) { if(i>1)   { int t;     t=Findmin(b,i-1);  return t<b[i-1]?t:b[i-1];   }   else return b[0]; } main() { int m,n,i,a[5][5],c[5];   for(i=1;i<=25;i++)   { if(i%5==0){n=4;m=i/5-1;}   else{n=i%5-1;m=i/5;}     scanf("%d",&a[m][n]);   }   for(m=0;m<=4;m++)   { int b[]={0};    for(n=0;n<=4;n++)    {b[n]=a[m][n];     printf("%d ",a[m][n]);    }  c[m]=Findmin(b,5);  printf("%d\n",c[m]);   } }

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">你在for(m=0;m&lt;=4;m++)循环中定义局部数组：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">int b[]={0};</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">因为初值只有一个0，因此此定义等价于：int b[1]={0}; 也就是b数组长度为1。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">执行&nbsp; for(n=0;n&lt;=4;n++)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;{ b[n]=a[m][n];</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;printf("%d ",a[m][n]);</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;}</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">给b[1]~ b[4]赋值就数组下标越界了，所以引起致命错误：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp; Stack around the variable'c' is corrupted </span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">也就是c变量周围的栈被毁掉了。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">你把定义 int b[]={0};</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">改为：int b[5]={0};</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">应该就没有问题了。</span></p>
