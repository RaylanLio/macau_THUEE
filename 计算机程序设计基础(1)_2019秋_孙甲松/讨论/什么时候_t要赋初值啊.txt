{
int *t;

}
我的想法//可以实现a,b的内容交换吗
void swap(int **a.int **b)
{
int **t;
t=a,a=b,b=t;
}

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">t=a, a=b, b=t;只会交换指针a和b的值，不能实现a,b的内容交换。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">t=*a,*a=*b,*b=*t; 是交换a和b所指单元的内容值。</span></p>
