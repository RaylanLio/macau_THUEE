在类模板中，是否可以将模板形参作为基类进行派生？
例如：
template<class T> class A { private:     class B :public T {……
是否可以将类模板作为基类派生出新的类模板呢？
例如：
template<class T>  class Base;
template<class T> class A{ private:     class B :public Base<T> {

孙甲松






 
 
  <p>可以从类模板派生出新的类，既可以<a href="https://baike.sogou.com/lemma/ShowInnerLink.htm?lemmaId=3825458&amp;ss_c=ssc.citiao.link" rel="nofollow">派生类</a>模板，也可以派生非模板类。派生方法为：</p> 
  <p>⑴ 从类模板派生类模板可以从类模板派生出新的类模板，它的派生格式如下例所示：</p> 
  <p>template &lt;class T&gt;</p> 
  <p>class base</p> 
  <p>{</p> 
  <p>……</p> 
  <p>};</p> 
  <p>template &lt;class T&gt;</p> 
  <p>class derive : public base&lt;T&gt;</p> 
  <p>{</p> 
  <p>……</p> 
  <p>};</p> 
  <p>与一般的类派生定义相似，只是在指出它的基类时要缀上模板参数，即base&lt;T&gt;。</p> 
  <p>⑵ 从类模板派生非模板类可以从类模板派生出非模板类，在派生中，作为非模板类的基类，必须是类模板实例化后的模板类，并且在定义派生类前不需要模板声明语句：template&lt;class&gt;。例如：</p> 
  <p>template &lt;class T&gt;</p> 
  <p>class base</p> 
  <p>{</p> 
  <p>……</p> 
  <p>};</p> 
  <p>class derive : public base&lt;int&gt;</p> 
  <p>{</p> 
  <p>……</p> 
  <p>};</p> 
  <p>在定义derive类时，base已实例化成了int型的模板类。</p> 
  <p>后面就可以直接定义derive类对象：</p> 
  <p>derive d1, d2;</p>
