问题：为什么先创建一个二进制文件并用fwrite语句写入数据之后，再用fread语句读取文件中数据到数组x中，输入与输出完全不同？
代码：写入数据
#include<stdio.h>
#include<stdlib.h>
#pragma warning(disable:4996)
main()
{
    FILE* fp;
    int i;
    unsigned long x[] = { 10010001,10011111,10011001,10011101,10011110,10010011 };
    if ((fp = fopen("abc.dat", "wb"))== NULL)
    {
         printf("cannot open this file!\n");
         exit(0);
    }
    fwrite(x, sizeof(unsigned long), 6, fp);
    fclose(fp);
    }
 
 
读入数据：
main()
{
    FILE* fp;
    int i;
    unsigned long x[] = {0};
    if ((fp = fopen("abc.dat", "wb"))== NULL)
    {
         printf("cannot open this file!\n");
         exit(0);
    }
    fread(x, sizeof(unsigned long), 6, fp);
    for (i = 0;i <= 5;i++)
    {
         printf("%ld", x[i]);
    }
    fclose(fp);
    }
 
 
输出结果为：
0-858993460-8589934603-858993460-858993460
与输入数据完全不同。

  <p>&nbsp;读入数据时，你程序的打开方式错误 ：</p> 
  <p>&nbsp; &nbsp; if&nbsp;((fp = fopen("abc.dat",&nbsp;"<strong>wb</strong>"))==&nbsp;NULL)</p> 
  <p>导致无法正确读入。</p> 
  <p>应改为：</p> 
  <p>&nbsp; &nbsp; if&nbsp;((fp = fopen("abc.dat",&nbsp;"<strong>rb</strong>"))==&nbsp;NULL)</p> 
  <p>&nbsp;</p> 
  <p>还有，你想读入6个长整数，定义语句：&nbsp;unsigned&nbsp;long&nbsp;x[] = {0};</p> 
  <p>最终根据初值个数认定数组长度为1，应改为：</p> 
  <p>&nbsp; &nbsp; &nbsp; unsigned&nbsp;long&nbsp;x[6] = {0};</p> 
  <p>&nbsp;</p>
