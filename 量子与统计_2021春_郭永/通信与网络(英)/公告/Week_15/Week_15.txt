Today we mainly talked about the transport layer and application layer. The transport layer in the TCP/IP suite is located between the application layer and the network layer. It provides services from the network layer. The transport layer acts as a liaison between a client program and a server program, a process-to-process connection. We introduced two transport-layer protocols, named UDP and TCP, respectively. UDP is a connectionless, unreliable transport protocol. TCP is a connection-oriented, reliable protocol. TCP explicitly defines connection establishment, data transfer, and connection tear-down phases to provide a connection-oriented service. For TCP, we will learn the concept of segments, slicing windows, timeouts, retransmission, connection setup, congestion control, and congestion avoidance in detail. 
The application layer provides services to the user. The whole Internet, hardware, and software were designed and developed to provide services at the application layer. We will also talk about socket, which is a process that sends messages into, and receives messages from, the network through a software interface.
