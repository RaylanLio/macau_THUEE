题目: 机房电脑常见问题解决方案
发布人: 陈放
发布时间: 2019-10-29 20:59

内容: 
1. 机房电脑无法联网：先双击电脑桌面“自动IP获取”，再联网。
 
2. 机房电脑Visual Studio 程序编译报错“error LNK1104: 无法打开文件 kernel32.lib”，先右键点击项目名称（项目名称在解决方案资源管理器中解决方案的下一行），点击 属性，在属性页中依次点击 配置属性-常规-平台工具集，将Visual Studio 2013 (v120) 改成 Visual Studio 2013 - Windows XP (v120_xp)，点击 确定。重新编译即可。
 
3. 机房电脑Visual Studio 程序执行一闪而过，看不到运行结果：在main函数结尾 return 0 前面加上一行代码 system("pause")；
 
4. 机房电脑屏幕显示字号过大：如果是电脑全局字号都过大的话，更改屏幕分辨率。
 
5. scanf不能用：文件开头加上#pragma warning(disable:4996)。
 
6. 无法打开xxx.exe：把先前运行的窗口关掉，如果还不行，检查任务管理器中是否还有该项目后台运行的进程，将其结束。
