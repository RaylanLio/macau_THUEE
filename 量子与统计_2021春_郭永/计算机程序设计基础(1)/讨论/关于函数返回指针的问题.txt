在做第10章探究题时，我在函数内将字符串成功转换，但是如果在内部定义字符串s，并在最后返回其地址，就会因为退出函数而使字符串成为乱码，我只能定义外部字符串s。我如何能在my_replace内部定义字符串并返回其地址，使得主函数可以使用该地址得到新字符串？
 
#include<stdio.h> #include<string.h> char s[200]; char *my_replace(char *s1,char *s2,char *s3) {     int i,j,k,m=strlen(s2),n=strlen(s3);     char *p=s,save[200]={'\0'},load[200]={'\0'},svoid[200]={'\0'};     strcpy(s,s1);     for(i=0;*p;i++,p++)     {         for(j=0;j-i<m&&*(p+j)==*(s2+j)&&*(p+j);j++);         if(j==m)         {             strcpy(save,(p+j));             strncpy(load,s,i);             strcat(load,s3);             strcat(load,save);             strcpy(s,load);             strncpy(load,svoid,200);             i+=n,p+=n;         }     }         return s; }
int main() {     char s1[200],s2[200],s3[200],*s;     gets(s1);gets(s2);gets(s3);     s=my_replace(s1,s2,s3);     printf("%s\n",s); }

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">让函数内定义的数组是在栈上开辟的局部数组，只要函数执行结束，数组的内存就会被释放掉，而使字符串成为乱码。外部数组因为不释放内存不会出现乱码。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">你应该在my_replace内部申请动态内存块来存放字符串并返回其地址，使得主函数可以使用该地址得到新字符串。</span></p>
