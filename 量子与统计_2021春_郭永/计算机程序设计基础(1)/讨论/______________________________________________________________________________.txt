  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">你这个方法确实有点过于简单粗暴了，运行会死循环没有结果。原因是，当while循环开始后，若循环条件表达式不为真，则n加1，但是a, b, c, d, e并没有随着n的变化而改变，所以整个循环条件表达式一直不为真，造成死循环。应该在n改变后，重新计算a, b, c, d, e的值：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">#include&lt;stdio.h&gt;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">main()</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">{</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; int n = 6, x, a, b, c, d, e;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; a = (n - 1) / 5;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; b = (4 * a - 1) / 5;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; c = (4 * b - 1) / 5;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; d = (4 * c - 1) / 5;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; e = (4 * d - 1) / 5;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; while ((n-1)%5!= 0 || (4*a-1)%5 != 0 || (4*b-1)%5 != 0 || (4*c-1)%5 != 0 || (4*d-1)%5 != 0)</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; {</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; n = n + 1;</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt"><strong>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; a = (n - 1) / 5;</strong></span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt"><strong>&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; b = (4 * a - 1) / 5;</strong></span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt"><strong>&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; c = (4 * b - 1) / 5;</strong></span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt"><strong>&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; d = (4 * c - 1) / 5;</strong></span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt"><strong>&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; e = (4 * d - 1) / 5;</strong></span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp; }</span></p>
