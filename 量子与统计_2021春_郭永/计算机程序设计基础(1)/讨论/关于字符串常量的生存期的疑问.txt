老师，对于这段代码：
#include <stdio.h> char* p = NULL; void Func() {  p = "RECT"; } int main() {  Func();  printf("%s", p);  return 0; }
如果放在.c文件中去运行，结果输出的是RECT,但是"RECT"是函数Func中出现的常量，当函数Func运行结束的时候，仍会输出RECT，这意味着字符串常量不会消亡？如果是这样，如果一个程序出现了很多个字符串常量，这不是很占用内存么？
而且，这段代码如果放到.cpp中按照C++去编译（VS2019），就会对p = "RECT"产生这样的错误提示：error C2440: “=”: 无法从“const char [5]”转换为“char *”
难道c++对这种现象进行了改进？

  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">你说的很对，字符串常量不会消亡，统统都放在常量区。字符串常量没有全局和局部之分。如果一个程序出现了很多个字符串常量，确实会很占用内存。</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">VS2019按照C++去编译，对p = "RECT"产生错误提示：</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; error C2440: “=”: 无法从“const char [5]”转换为“char *”</span></p> 
  <p style="margin-left:0cm; margin-right:0cm; text-align:justify"><span style="font-size:10.5pt">是因为C++更严格核对类型，编译器认为字符串"RECT"是const char [5]类型，而p是char *类型，p = "RECT";两侧的类型不一致。你可以改为：p = (char *)"RECT"; 再试一下。</span></p>
