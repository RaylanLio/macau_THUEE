  <p>你的主函数中ap和bp是结构体指针，应该申请一块SN大小的结构体，为什么写为申请SN *指针内存？</p> 
  <p>ap = ( SN * ) malloc (sizeof(SN *));</p> 
  <p>bp = ( SN * ) malloc (sizeof(SN *));</p> 
  <p>应改为：</p> 
  <p>ap = ( SN * ) malloc (sizeof(SN));</p> 
  <p>bp = ( SN * ) malloc (sizeof(SN));</p> 
  <p>&nbsp;</p>
